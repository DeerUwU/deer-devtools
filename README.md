# deer-devtools
Various dev tools i use for game development in godot. You can customize the addon's behavior in your project settings.

## Features:
### Copy C# node reference 
Adds a context menu option to copy a node path using C# syntax.
### Auto bumping build numbers
Automatically set the project's build number either when you build the project or export it. You can also generate a version string with customizable formatting.

## Installation:
Navigate to your project's addons folder `projectname/addons/` inside a terminal and run `git submodule add https://github.com/DeerUwU/deer-devtools/`.
Now build the solution once and then enable the addon afterwards.
